# 🐉 Dragon Art Project

Добро пожаловать в **Dragon Arts** — проект об искусстве драконов, энциклопедиях фэнтези и нашем собственном мире.

## Что внутри
- Галерея Dragon Arts и отдельные страницы персонажей с лором и логовами.
- Авторский мир фэнтези с элементами науки: люди, разумные драконы и грифоны, магия и связь драконов со стихиями.
- Энциклопедии драконов из разных вымышленных вселенных.
- Материалы для оригинальной серии книг **«Путешественники драконьих небес»**.

## Сайт
Главная страница — `index.html`; стили и данные галереи находятся в `assets/`. Публикация настроена через GitHub Pages (`.github/workflows/pages.yml`).

Чтобы добавить арт, загрузите файл в `art/dragons/` с именем, указанным в `assets/data.js`. Изображения, созданные в чате, не переносятся в репозиторий автоматически: их необходимо загрузить отдельно.

## Dragon Arts: новые записи
В октябре 2026 года энциклопедия пополнилась Кристалоном, Аврелионом, Морвейном, Терраксом, Нерелиусом, Эондаром, Сонарисом и Вейларисом. Добавлены также Сайрен и Темерайр. Новые записи доступны из галереи и содержат подтверждённые детали лора; незаданные характеристики отмечены как находящиеся в разработке.

### Роман «Путешественники драконьих небес»
**Книга I: «Небесный Исток»** — план из 25 глав. В центре истории — карта с семью небесными печатями, легендарный Небесный Исток, исчезнувшая цивилизация и меняющиеся воздушные течения. Сайрен — загадочный кристаллический дракон без всадника, понимающий древние знаки; его происхождение связано с картой.

Подробный рабочий синопсис: [lore/books/sky-travellers-book-1.md](lore/books/sky-travellers-book-1.md).
