# 🐉 Dragon Art Project

Добро пожаловать в **Dragon Art Project** — проект, посвящённый драконам, фэнтези-арту, энциклопедиям и созданию собственного мира драконов.

## 🌟 О проекте

Здесь будут собираться:

- 🎨 арты и художественные референсы драконов;
- 📚 энциклопедии драконов из разных вселенных;
- 🌍 лор и история собственного мира;
- 🐲 виды, подвиды и уникальные драконы;
- 👤 персонажи и наездники;
- 🗺️ карты, регионы и важные места;
- 💻 материалы для будущего сайта Dragon Art Project.

## 🐲 Энциклопедии

В проекте планируется создавать большие структурированные энциклопедии драконов с такими полями, как:

- имя;
- вид и подвид;
- стихия;
- внешний вид;
- размеры;
- способности;
- характер;
- место обитания;
- история;
- наездник или хозяин;
- судьба;
- источники.

## 🌌 Собственный мир

Отдельная часть проекта будет посвящена авторскому миру драконов: его видам, народам, персонажам, регионам, истории и мифологии.

## 🎨 Арт

Папка `art/` предназначена для собственных работ и референсов. Для сторонних материалов будут сохраняться сведения об источнике и авторе, когда это необходимо.

## 🚀 План развития

1. Создать базовую структуру проекта.
2. Добавить первые энциклопедии драконов.
3. Разработать лор собственного мира.
4. Добавить собственные арты и персонажей.
5. Создать сайт проекта. ✅
6. Связать сайт с энциклопедиями и материалами проекта.

## 🌐 Сайт Dragon Arts

В репозитории уже создана первая версия сайта-галереи:

- `index.html` — главная страница;
- `assets/` — стили и данные галереи;
- `art/dragons/` — изображения наших драконов;
- `.github/workflows/pages.yml` — автоматическая публикация через GitHub Pages.

Чтобы добавить арт, поместите изображение в `art/dragons/` и укажите его путь в `assets/data.js`.

> Примечание: уже созданные в ChatGPT изображения не загружаются в GitHub автоматически, поэтому файлы артов нужно отдельно добавить в папку `art/dragons/`.
