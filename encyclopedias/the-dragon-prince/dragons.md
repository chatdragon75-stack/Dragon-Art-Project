# 🐲 Драконы

> Рабочий каталог. Новые записи добавляются после проверки канонических источников.

## Архидраконы

### Зубея (Zubeia)
- **Вид:** Архидракон неба
- **Стихия:** Небо
- **Роль:** Королева драконов; мать Зим
- **Известные связи:** Зим, Аваизандум
- **Примечание:** Один из центральных драконьих персонажей истории.

### Аваизандум (Avizandum)
- **Вид:** Архидракон неба
- **Стихия:** Небо
- **Роль:** Бывший король драконов
- **Известные связи:** Зубея, Зим
- **Примечание:** Известен как Громовой дракон.

### Зим / Азимондиас (Zym / Azymondias)
- **Вид:** Молодой архидракон неба
- **Стихия:** Небо
- **Роль:** Принц драконов
- **Известные связи:** Зубея, Аваизандум, Каллум, Рейла, Эзран
- **Примечание:** Один из главных персонажей сериала.

## Другие известные драконы

### Сол Регем (Sol Regem)
- **Вид:** Архидракон солнца
- **Стихия:** Солнце
- **Роль:** Бывший король драконов
- **Примечание:** Один из древнейших и наиболее могущественных драконов мира.

### Регем (Regem)
- **Примечание:** Запись требует уточнения при расширении каталога; не объединять автоматически с Сол Регемом без проверки источника.
