# 📚 Источники

Этот файл предназначен для фиксации канонических материалов, использованных при составлении энциклопедии.

## Приоритет источников

1. Официальные материалы франшизы.
2. Эпизоды и официальные книги / дополнительные материалы.
3. Официальные справочные материалы создателей.
4. Надёжные вторичные источники — только для уточнения и с пометкой.

## Правило энциклопедии

Если информация не подтверждена каноном, она не должна подаваться как установленный факт. Спорные или неполные сведения будут отмечаться отдельно.
