# 🐉 Энциклопедия драконов — The Dragon Prince

Энциклопедия драконов и драконьих видов из вселенной **The Dragon Prince**.

## Разделы

- `dragons.md` — каталог известных драконов и драконьих персонажей
- `species.md` — виды, архидраконы и стихии
- `sources.md` — источники и примечания

## Система классификации

Для каждого дракона по возможности указываются:

- имя;
- вид / титул;
- стихия;
- внешний вид;
- размеры;
- способности;
- характер;
- место обитания;
- связи с персонажами;
- судьба;
- источники.

> Энциклопедия будет расширяться по мере проверки канонических материалов.
