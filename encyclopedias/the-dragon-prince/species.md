# 🌌 Виды и стихии драконов

## Основные источники магии

В мире **The Dragon Prince** драконы связаны с Примальными источниками магии.

| Источник | Связанные драконы / примеры |
|---|---|
| Небо | Аваизандум, Зубея, Зим |
| Солнце | Сол Регем |
| Земля | Будет дополнено |
| Луна | Будет дополнено |
| Звёзды | Будет дополнено |
| Океан | Будет дополнено |

## Архидраконы

Архидраконы — высшие и особенно могущественные представители драконов, связанные с различными Примальными источниками.

> Список и классификация будут расширяться после проверки канона.
