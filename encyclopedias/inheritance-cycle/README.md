# The Inheritance Cycle — Энциклопедия драконов

Энциклопедия драконов, всадников, драконьих видов и мира **The Inheritance Cycle** Кристофера Паолини.

## Разделы

- `dragons.md` — драконы и их подробные карточки
- `species.md` — виды, окрасы и особенности драконов
- `riders.md` — всадники и связанные с ними драконы
- `locations.md` — важные места, связанные с драконами
- `history.md` — история драконов и Всадников
- `sources.md` — источники и примечания к канону

## Шаблон карточки дракона

- Имя
- Пол
- Вид / происхождение
- Окрас и внешность
- Размер
- Способности
- Характер
- Всадник / связь с персонажами
- Место обитания
- История
- Судьба
- Источники

> В энциклопедии отдельно отмечаются подтверждённые сведения канона и спорные/неподтверждённые данные.
